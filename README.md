Sistema Bancário POO

Sistema bancário em Python utilizando os pilares da Orientação a Objetos: abstração, herança, polimorfismo e encapsulamento.

Funcionalidades
- Depósito, saque e extrato
- Controle de limite e saques diários por conta
- Histórico de transações com data e hora
- Cadastro de clientes e contas correntes

Como executar
python sistema_bancario.py

Estrutura de classes
- Transacao (ABC) → Deposito, Saque
- Conta → ContaCorrente
- Cliente → PessoaFisica
